# Цвета настроения (MoodTracker)

Приложение для отслеживания настроения по дням с цветной календарной сеткой.

## Возможности

- 📅 Годовой календарь с цветными квадратиками для каждого дня
- 🎨 8 уровней настроения (от «Вау» до «Отвратительный день») + радужный «Вау»
- 🔔 Ежедневное напоминание в 22:00 заполнить настроение
- 📊 Простая статистика по году
- 🌙 Поддержка тёмной и светлой темы
- 🇷🇺 Полностью на русском языке

## Как пользоваться

1. Нажми на любой день — откроется выбор настроения
2. Выбери цвет / уровень
3. Смотри, как заполняется календарь
4. Напоминание приходит каждый вечер в 22:00

## Сборка

APK собирается автоматически через GitHub Actions при каждом пуше в `main`.

Скачать готовый APK можно во вкладке **Actions** → последний успешный workflow → Artifacts → `MoodTracker-APK`.
